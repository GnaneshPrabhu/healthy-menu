# Healthy Menu

Customer-facing menu for the new food business project.

The site reads products, categories, prices and business settings from Supabase. The QR will point to the final HTTPS site URL, so changing a product or price in the admin will update the menu without changing the QR.

The visible brand is intentionally a placeholder until the final brand name is selected.

Next phases: secure server-side order pricing, Supabase Auth admin login, product/category management, image storage, GitHub-to-Netlify deployment, and QR generation.
